# PRINCO — site vitrine HTML/CSS/JS

## Lancer
1. Décompressez le ZIP.
2. Ouvrez le dossier dans VS Code.
3. Ouvrez `index.html` dans le navigateur ou lancez Live Server.

## Fichiers
- `index.html` : page d'accueil, services, portfolio et guides SEO.
- `style.css` : design responsive et styles des pages.
- `script.js` : menu mobile et année automatique.
- `princo-logo.png` : logo PRINCO fourni.
- `seo-video-ia-tunisie.html` : guide SEO sur la production de vidéos IA.
- `seo-sponsoring-tunisie.html` : guide SEO sur le sponsoring digital.

## À personnaliser avant publication
- Vérifiez le rendu du logo transparent dans le navigateur.
- Remplacez les photos de démonstration par vos réalisations originales.
- Vérifiez les liens sociaux et ajoutez les profils exacts.
- Pour un SEO plus complet, ajoutez un nom de domaine, sitemap.xml, robots.txt, Google Search Console et des données structurées adaptées.
- Les pages sont des guides informatifs, pas un classement affirmant qu'une agence est « la meilleure » sans critères vérifiés.

Les photos distantes nécessitent une connexion Internet.
